# Organizador de Música

## Descripción

Organizador de Música es una aplicación sencilla creada con HTML y CSS para organizar canciones de manera clara y ordenada.

## Características

- Buscar canciones.
- Visualizar una lista de canciones.
- Agregar canciones.
- Interfaz sencilla y fácil de usar.
- Diseño adaptable a diferentes dispositivos.

## Tecnologías utilizadas

- HTML5
- CSS3
